## 📘 About the Repository

This repository contains the practical work and supporting learning credentials for the Database Management Systems (DBMS) laboratory.

The experiment reports are provided as PDF documents. Each report is organized by experiment number to make it easy to access and review the submitted practical work. The repository also includes SQL certificates that document additional learning in SQL fundamentals and intermediate-level concepts.

### Objectives

- Develop an understanding of relational database concepts.
- Practice SQL and database-related laboratory exercises.
- Maintain experiment reports in a structured digital format.
- Keep supplementary SQL learning certificates alongside the practical work.
- Create an accessible record of DBMS laboratory submissions.
